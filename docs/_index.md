Golem is an extensible personal AI agent. It runs on your computer, serves a local web UI, and talks to models through extensions you install.

It does not ship a built-in model. A **provider** extension (for example OpenRouter) is the model backend. A **channel** extension (for example Telegram) is another way to send messages in. You can write both with the Python SDK.

Start here:

1. [Install](getting-started/install.md) Golem on macOS or Linux.
2. Follow the [quickstart](getting-started/quickstart.md) to run the server, add a provider, and send a first message.
